## Ordnerstruktur

```
werbevideo-shots/
├── README.md              ← diese Datei
├── docs/                  ← Shotlist · Animatic · Untertitel-/VO-Timecode
├── storyboard/            ← Detail-Storyboard-Bilder (1–9, 10–18)
├── voices/                ← VO-Rough (mp3)
├── assets/subtitles/      ← Untertitel-Overlay-PNGs (Arbeitsversion)
├── review/                ← ★ aktuelle Review-Dateien
│   ├── videos/
│   ├── stills/
│   └── notes/
└── work/                  ← Zwischenstände (meist nicht ansehen)
    ├── frames/            ← Render-Frame-Sequenzen
    ├── drafts/            ← ältere Einzel-Shot-mp4s
    ├── tests/             ← Schrift-/Untertitel-Stiltests
    ├── checks/            ← Chroma-/Prüf-Stills
    └── subs/              ← .ass / .srt
```
